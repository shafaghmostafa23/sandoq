# صندوق قرض‌الحسنه · مینی‌اپ بله

یک مینی‌اپ فارسی و راست‌چین برای اعضای صندوق و یک پنل مدیریت با همان سبک روشن و آبی نمونهٔ طراحی. پوشهٔ public شامل رابط کاربری، server.mjs شامل API و db/schema.sql طرح PostgreSQL است.

## اجرای نمونه

نیازمند Node.js نسخهٔ ۲۰ یا جدیدتر:

    npm install
    cp .env.example .env
    npm start

سپس http://localhost:3000 را برای اپ عضو و http://localhost:3000/admin را برای پنل باز کنید.

ورود آزمایشی پنل: admin / demo1234. اپ عضو امکان انتخاب رضا احمدی یا حسن جعفری را دارد؛ حسن دو دفتر تخصیص‌یافته و وام نمونه در هر دو دفتر دارد. اطلاعات نمونه با توقف سرور پاک می‌شود. هیچ پرداختی در حالت نمونه انجام نمی‌شود.

## راه‌اندازی زنده

1. PostgreSQL ایجاد کنید، فایل env نمونه را کپی کنید و این موارد را تنظیم کنید:
   - DEMO_MODE=false
   - NODE_ENV=production
   - DATABASE_URL و در صورت نیاز DATABASE_SSL=true (با اعتبارسنجی گواهی سرور)
   - ADMIN_USERNAME و یک ADMIN_PASSWORD قوی
2. npm install را اجرا کنید. سرور هنگام شروع db/schema.sql را اجرا می‌کند. ورود اولیهٔ اعضا، دفترها، تخصیص‌های member_offices، وام‌ها و اقساط باید از سامانهٔ مهاجرت یا ورود اطلاعات صندوق انجام شود. تمام مبلغ‌های ذخیره‌شده در جدول‌ها تومان هستند؛ API پرداخت بله مبلغ را برای کیف‌پول به ریال تبدیل می‌کند.
3. HTTPS را پشت reverse proxy فعال کنید. دامنهٔ HTTPS را به‌عنوان آدرس Mini App بازو در @botfather ثبت کنید.
4. برای اتصال ورود مینی‌اپ، BALE_BOT_TOKEN را در سرور قرار دهید. در پنل، برای هر عضو شناسهٔ کاربر بله را ثبت کنید. اگر کاربر هنوز متصل نشده باشد، مینی‌اپ شناسه‌ای را که از initData معتبر سمت سرور استخراج شده به او نشان می‌دهد تا مدیر آن را بررسی و به عضو وصل کند.
5. برای پرداخت کیف‌پولی، BALE_PROVIDER_TOKEN را از @botfather دریافت کنید. برای آزمایش می‌توان از توکن آزمایشی رسمی WALLET-TEST-1111111111111111 استفاده کرد؛ این توکن انتقال پول واقعی انجام نمی‌دهد. پرداخت کیف‌پولی فقط زمانی در رابط فعال می‌شود که BALE_BOT_TOKEN، BALE_PROVIDER_TOKEN و BALE_WEBHOOK_SECRET روی سرور تنظیم شده باشند.
6. وب‌هوک بازو را روی URL HTTPS زیر تنظیم کنید و به‌جای دامنه و راز، مقدار واقعی خود را بگذارید:

    https://your-domain.example/api/webhooks/bale/your-long-random-secret

   مسیر وب‌هوک را با API رسمی setWebhook ثبت کنید. برای نمونه:

    curl -X POST 'https://tapi.bale.ai/bot<BALE_BOT_TOKEN>/setWebhook' -H 'Content-Type: application/json' -d '{"url":"https://your-domain.example/api/webhooks/bale/<BALE_WEBHOOK_SECRET>"}'

   مسیر را محرمانه نگه دارید و فقط از HTTPS استفاده کنید. Bot API در مستندات بررسی‌شده برای Update وب‌هوک امضای جداگانه‌ای تعریف نمی‌کند؛ بنابراین سرور علاوه بر مسیر محرمانه، payload، شناسهٔ کاربر و مبلغ را با دادهٔ فاکتور خودش تطبیق می‌دهد و شناسهٔ تراکنش pre_checkout_query را نیز با شناسهٔ پرداخت موفق و نتیجهٔ inquireTransaction تطبیق می‌کند. تکرار Update، شناسهٔ تراکنش و شارژ در پایگاه‌داده idempotent است.

## رفتار پرداخت

- Mini App از createInvoiceLink استفاده می‌کند و همان رشتهٔ پاسخ را به openInvoice می‌دهد. شناسهٔ تراکنش pre_checkout_query به payload همان فاکتور متصل و یکتا ذخیره می‌شود؛ در SuccessfulPayment نیز شناسهٔ telegram_payment_charge_id باید با آن و با id استعلام inquireTransaction برابر باشد. پرداخت فقط پس از پاسخ paid از استعلام مستقیم بله روی قسط اعمال می‌شود.
- اگر صفحهٔ بله پرداخت لغوشده یا ناموفق برگرداند، همان درخواست به سرور عضو متصل می‌شود تا قسط برای تلاش دوباره باز شود؛ نتیجهٔ نهایی هر callback موفق همچنان از بله استعلام می‌شود.
- طبق مستندات رسمی بله، پرداخت کیف‌پولی به کیف‌پول توسعه‌دهندهٔ بازو واریز می‌شود. این مسیر به معنی واریز مستقیم به حساب بانکی صندوق نیست. مقصد کیف‌پول و روند تسویه را قبل از فعال‌سازی زنده بررسی کنید.
- بعد از پرداخت کیف‌پولی، سرور شناسهٔ پیگیری بله را ثبت می‌کند و رسید را در گفت‌وگوی بله می‌فرستد. ثبت دستی فیش یا کد پیگیری هم یک شماره مرجع صندوق می‌گیرد؛ اعلام دستی تا زمان تایید یا رد مدیر روی قسط اعمال نمی‌شود.
- تراکنش‌های بانکی فعلاً دادهٔ نمونه/ورودی لایهٔ اتصال هستند. اتصال خودکار گردش حساب به API یا فایل بانکی نیاز دارد و در این نسخه ادعا نشده است.
- فایل‌های رسید به‌صورت خصوصی در uploads نگهداری می‌شوند و دریافت آن‌ها فقط برای نشست مدیر مجاز است. برای تولید از فضای ذخیره‌سازی خصوصی و پشتیبان‌گیری مناسب استفاده کنید.

## API و مدل داده

API در همان سرور و بدون CORS عمومی ارائه می‌شود. نشست‌ها در کوکی HttpOnly و SameSite نگهداری می‌شوند. ورود Mini App، initData را با HMAC-SHA-256 و auth_date اعتبارسنجی می‌کند؛ initDataUnsafe در مرورگر مبنای اعتماد نیست. نشست مدیر و عضو از هم جدا هستند. API شناسهٔ عضو و دسترسی او به وام/قسط را قبل از ثبت پرداخت بررسی می‌کند.

پوشش API شامل ورود نمونه/بله، داشبورد عضو، ثبت پرداخت دستی، ایجاد فاکتور بله، وب‌هوک پرداخت، مدیریت اعضا و دفترها، ساخت وام و برنامه اقساط، تخصیص چند دفتر به عضو، اتصال شناسه بله، بررسی پرداخت و تایید/رد با علت است. db/schema.sql جدول‌های members، offices، member_offices، loans، installments، manual_payments، native_payments، bank_transactions و audit log را ایجاد می‌کند.

- https://docs.bale.ai/ — sendInvoice، createInvoiceLink، answerPreCheckoutQuery، SuccessfulPayment و inquireTransaction
